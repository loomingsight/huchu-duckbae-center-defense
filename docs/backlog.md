# 후추덕배 디펜스 백로그

작성일: 2026-07-21

## 완료

### HD-BL-001 보스 출현 방향을 12시로 고정

- 상태: 완료 (2026-07-21)
- 요구사항: 모든 보스는 맵의 12시 방향 진입 지점에서 출현한다.
- 완료 조건:
  - 개장수와 불법번식장 운영자가 항상 12시 방향에서 출현한다.
  - 일반 적의 출현 위치와 경로 선택 규칙은 변경하지 않는다.
  - 보스의 이동, 방향 전환, 공격 및 개장수 트럭 연출이 12시 진입 경로에서 자연스럽게 이어진다.
  - 보스 종류별 출현 위치를 자동화 테스트로 고정한다.
- 구현 근거: 보스 경로를 `P3`로 고정하고 여러 시드에서 개장수·불법번식장 운영자의 출현 경로를 단위 테스트로 검증했다.

### HD-BL-002 꼬리치기 애니메이션 가시성 강화

- 상태: 완료 (2026-07-21)
- 요구사항: 꼬리치기 애니메이션의 표시 크기를 현재의 2.5배로 확대하고, 재생 속도를 현재의 0.5배로 낮춘다.
- 완료 조건:
  - 시각 효과의 너비와 높이가 현재 기준 2.5배로 표시된다.
  - 재생 속도는 0.5배가 되어 전체 표시 시간은 현재의 2배가 된다.
  - 모바일 화면에서 후추·덕배와 적에게 가려지지 않고 타격 방향을 알아볼 수 있다.
  - 피해량, 넉백, 둔화, 공격 판정 범위와 쿨다운은 변경하지 않는다.
- 구현 근거: 꼬리치기 원호와 먼지 효과를 2.5배로 확대하고 표시 시간을 250ms에서 500ms로 늘렸으며, 전투 수치는 변경하지 않았다.

### HD-BL-003 안전신문고 시각 효과를 `신고!` 글자로 교체

- 상태: 완료 (2026-07-21)
- 요구사항: 안전신문고 발동 시 종이 고지서 효과를 제거하고, 대상마다 굵은 주황색 한글 `신고!`를 표시한다.
- 완료 조건:
  - 기존 종이 및 도장 형태의 시각 효과가 나타나지 않는다.
  - 안전신문고 대상 각각의 라벨 위에 정확히 `신고!`가 굵은 주황색으로 표시된다.
  - 글자는 모바일 화면에서도 즉시 읽을 수 있고, 피해 적용 시점을 분명하게 보여준다.
  - 맵 전체 대상 선정, 일반 적·보스 피해량 및 자동 시전 규칙은 변경하지 않는다.
- 구현 근거: 공유 전투 아틀라스에 굵은 주황색 `신고!` 글리프를 추가해 대상별로 표시하고, 모바일 화면에서 캐릭터 및 이름표와 겹치지 않는 위치를 확인했다.

### HD-BL-004 꼬리치기 넉백을 중앙 바깥 방향으로 통일

- 상태: 완료 (2026-07-21)
- 요구사항: 꼬리치기에 맞은 적이 보호소가 있는 맵 중앙에서 멀어지는 방향으로 밀려난다.
- 완료 조건:
  - 실제 적 위치는 기존 진입 경로를 따라 중앙 바깥쪽으로 35px 이동한다.
  - 순간 리코일 애니메이션은 보호소 중심에서 피격 적 위치로 향한다.
  - 적이 보호소 중심과 같은 좌표이면 12시 방향을 기본값으로 사용한다.
  - 피해량, 둔화, 판정 범위, 쿨다운과 다른 공격의 피격 방향은 변경하지 않는다.
- 구현 근거: 꼬리치기 피해에만 보호소 중심 기준 정규화 방향을 적용하고, 중심 좌표 기본값과 비꼬리 공격 회귀를 단위 테스트로 검증했다.
