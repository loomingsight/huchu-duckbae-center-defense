# 잔여 백로그 일괄 구현 설계

작성일: 2026-07-21  
대상: HD-BL-007 ~ HD-BL-011

## 목표

플레이 중 끊겨 보이는 적 이동과 꼬리치기 가독성을 바로잡고, 승인된 보스 및 스킬 밸런스를 일관된 데이터 흐름으로 반영한다. 변경 후 모바일 중심 MVP가 기존 조작·공격·웨이브 흐름을 유지해야 한다.

## 범위

- 오프리시 보호자의 주기적 도약 제거와 연속 이동 보장
- 꼬리치기의 동심원 계열 별도 이펙트 제거
- 꼬리치기 캐릭터 애니메이션 마지막 프레임 800ms 유지
- 개장수와 불법 번식업자의 이동속도 20% 증가
- 새로 배운 스킬의 첫 쿨타임을 1초로 통일
- 꼬리치기 일반 쿨타임 8초에서 6초로 단축
- 안전신문고 일반 쿨타임 22초에서 19초로 단축
- 안전신문고 구매 비용을 현재 구매 단계 기본 비용보다 간식 5개 높게 책정
- 백로그 문서 상태 갱신, 회귀 검증, GitHub Pages 배포

## 현재 원인

### 오프리시 보호자 이동

`EnemySystem`은 오프리시 보호자에게 4초마다 경로 진행도를 한 프레임에 64만큼 더하는 대시를 적용한다. 렌더링 객체의 누락이 아니라 게임 상태 자체가 순간 이동하므로, 보간이나 페이드만 추가하면 도약은 남는다.

### 꼬리치기 가독성

전투 이펙트 풀은 꼬리치기마다 큰 원형 호와 원형으로 배치된 먼지를 함께 그린다. 캐릭터의 꼬리 동작보다 동심원 효과가 먼저 보인다. 캐릭터 애니메이션은 6프레임, 12fps이지만 몸동작 지속시간이 500ms라 마지막 프레임은 약 83ms만 보인다.

### 스킬 구매 비용

진행 시스템과 하단 스킬 독은 모든 스킬에 동일한 현재 단계 비용만 사용한다. 안전신문고의 고정 가산 비용을 정확히 표시하고 차감하려면 양쪽에서 동일한 비용 계산 규칙을 공유해야 한다.

## 검토한 접근

### A. 원인 제거와 단일 정책 함수 사용 — 채택

- 순간 대시 상태 전이를 제거하고 기존 연속 이동 속도만 사용한다.
- 꼬리치기의 별도 원형 이펙트를 제거하고 캐릭터 마지막 프레임을 800ms 유지한다.
- 안전신문고 비용은 공용 비용 계산 함수로 UI 표시와 실제 차감을 동일하게 만든다.

장점은 동작 원인을 직접 제거하고 표시값과 실제값의 불일치를 막는다는 점이다. 기존 타입 일부를 호환용으로 유지할 수 있어 변경 범위도 제한적이다.

### B. 렌더 보간으로 대시를 숨김 — 기각

화면상 이동만 보간하면 적의 충돌·도착 판정은 여전히 한 프레임에 크게 이동한다. 낮은 프레임률에서 다시 튀어 보일 수 있어 근본 해결이 아니다.

### C. 꼬리치기 원형 효과를 약하게 유지 — 기각

불투명도나 크기를 줄여도 사용자가 제거를 요청한 동심원 모양이 남고, 캐릭터 동작의 가독성을 계속 방해한다.

## 상세 설계

### 연속 적 이동

- 오프리시 보호자 전용 대시 거리와 주기 경계 처리를 삭제한다.
- 고정 스텝마다 `speed * dt * multiplier`만큼 경로 진행도를 증가시킨다.
- 감속 종료 경계 분할은 유지해 큰 스텝과 작은 스텝의 결정론을 보존한다.
- 저장·스냅샷 호환을 위해 대시 잔여 필드가 남는 경우 항상 0을 사용한다.
- ETA 계산에서도 대시를 제거하고 동일한 연속 이동 모델을 사용한다.

### 꼬리치기 연출

- 꼬리치기 적중 시 원형 호와 원형 먼지 액터를 생성하지 않는다.
- 피해 숫자, 넉백, 감속, 사운드와 햅틱은 그대로 유지한다.
- 마지막 프레임 시작 시각은 `(frameCount - 1) / fps`로 계산한다.
- 몸동작 종료 시각은 마지막 프레임 시작 시각에 800ms를 더한다.
- 게임 루프는 멈추지 않으며, 유지 중에도 이동·적 AI·다른 이펙트가 계속 진행된다.

### 보스 속도와 애니메이션

- 개장수 속도: 25 → 30
- 불법 번식업자 속도: 23 → 27.6
- 보스 걷기 애니메이션 시계에도 1.2배율을 적용해 이동과 발걸음의 체감이 어긋나지 않게 한다.
- 개장수 트럭 리그와 일반 보스 액터가 같은 배율 함수를 사용한다.

### 스킬 쿨타임

- 스킬 학습 직후 `readyAt = learnedAt + 1000ms`로 설정한다.
- 첫 자동 시전이 성공하면 해당 스킬의 일반 쿨타임으로 전환한다.
- 대상이 없어 시전하지 못하면 준비 상태를 유지한다.
- 쿨타임 진행률은 현재 쿨타임 창을 분모로 사용해 첫 1초도 0에서 100%까지 자연스럽게 표시한다.
- 일반 쿨타임은 꼬리치기 6000ms, 아쿠아빔 기존값 유지, 안전신문고 19000ms다.

### 안전신문고 비용

- 구매 단계 기본 비용은 기존 15, 25, 40을 유지한다.
- 안전신문고만 선택 시 실제 비용을 20, 30, 45로 계산한다.
- 가산값은 학습 순서의 현재 단계에 한 번만 적용하며 다음 단계로 누적하지 않는다.
- 하단 독의 숫자, 구매 가능 하이라이트, 구매 검증, 실제 차감이 동일한 공용 함수를 사용한다.

## 테스트와 검증 정책

사용자 지시에 따라 숫자 정책 변경만을 위한 신규 전용 테스트는 만들지 않는다. 기존 테스트의 하드코딩 기대값은 새 정책에 맞춘다. 오프리시 도약과 꼬리 애니메이션은 시각·동작 버그이므로 실패하는 회귀 테스트를 먼저 만들고 수정한다.

최종 검증은 다음을 포함한다.

- 전체 단위 테스트
- 타입 검사와 프로덕션 빌드
- 기존 시각 회귀 테스트 중 변경 범위에 관련된 시나리오
- 실제 모바일 뷰포트에서 오프리시 연속 이동, 꼬리 마지막 프레임, 비용·쿨타임 표시 확인
- GitHub Actions Pages 워크플로 성공과 배포 URL 응답 확인

## 비범위

- 사운드 시스템 변경
- 보호소나 맵 아트 변경
- 기존 사용자가 보유한 시각 스냅샷 두 파일의 갱신 또는 커밋
