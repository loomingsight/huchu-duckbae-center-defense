# 중앙 바깥 방향 꼬리치기 넉백 설계

작성일: 2026-07-21
상태: 승인됨

## 목표

꼬리치기에 맞은 적이 보호소가 있는 맵 중앙에서 바깥쪽으로 밀려나는 움직임을 일관되게 보여준다.

## 적용 범위

- 실제 전투 위치는 기존처럼 적의 경로 진행도를 35px 되돌린다. 모든 경로가 보호소를 향하므로 적은 자기 진입 경로를 따라 중앙에서 멀어진다.
- 꼬리치기의 순간 리코일 애니메이션은 보호소 중심 `(270, 480)`에서 피격 적 위치로 향하는 정규화 벡터를 사용한다.
- 적이 정확히 보호소 중심에 있으면 결정적인 기본 방향인 12시 방향 `(0, -1)`을 사용한다.
- 짖기, 덕배 공격, 아쿠아빔, 안전신문고와 적의 보호소 공격 방향은 기존 규칙을 유지한다.
- 꼬리치기의 피해량, 35px 넉백 거리, 둔화 배율·시간, 판정 범위와 쿨다운은 변경하지 않는다.

## 구현 구조

`ImpactFeedbackSystem`이 `damageApplied` 이벤트를 처리할 때 `source === 'tailSwipe'`인 적 피격만 별도 방향을 계산한다. 이벤트에 이미 포함된 피격 위치와 `BALANCE.shelter` 중심을 사용하므로 새로운 런타임 상태나 렌더 객체는 만들지 않는다. 실제 위치 이동은 현재 `EnemySystem.applyTailEffect()`의 경로 진행도 감소를 그대로 사용한다.

## 검증

- 단위 테스트에서 공격자 위치나 기존 충격 방향과 무관하게 꼬리치기 리코일이 보호소 중심에서 적 바깥쪽을 향하는지 확인한다.
- 보호소 중심과 적 위치가 같은 경우 12시 기본 방향을 확인한다.
- 다른 피해원의 리코일 방향이 바뀌지 않는지 회귀 테스트로 확인한다.
- 전체 단위 테스트, 타입 검사, 프로덕션 빌드와 모바일 브라우저 전투 시나리오를 실행한다.

## 커밋 및 배포

- GitHub Actions의 Pages 배포 완료와 공개 URL 응답을 확인한다.
